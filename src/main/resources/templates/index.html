01 / 03
  1. 01

    外部协议认证

    IDENTITY PROVIDER

    Spring Security 校验 state 和回调；配置 OIDC 时还会验证 ID Token。应用不接触用户密码。

    本地用户users.email + tenantId
  2. 02

    映射本地账户

    LOCAL ACCOUNT

    从 provider 属性映射已验证邮箱和姓名；按邮箱查找用户，并校验用户与 OAuth2 Client 属于同一租户。

    account登录后生成
  3. 03

    签发平台令牌

    PLATFORM JWT

    平台为本地账户签发自己的短期 JWT，资源 API 只验证平台令牌。

    audoauth2-client-platform-api

两种令牌，两个边界。 Google 的令牌代表外部身份；平台 JWT 代表本地账户对平台 API 的访问。
